Премиальный, высококонверсионный адаптивный лендинг для стоматологической клиники **Like Clinic** в г. Алматы (ул. Гоголя, 20).

Разработан с соблюдением стандартов **UI/UX Pro Max**, дизайн-системы клиники и строгим контролем качества иконографики (100% чистый векторный SVG, полное отсутствие растровых смайликов).

---

## 🌟 Ключевые особенности

### 📱 Мобильная адаптивность первого класса (Mobile-First)
* **Slide-up Mobile Drawer**: выезжающее мобильное меню с эффектом матового стекла (`backdrop-filter: blur(20px)`), удобной навигацией, быстрым звонком и переходом в WhatsApp.
* **Floating Bottom Island**: зафиксированная нижняя плавающая панель на смартфонах с прямым вызовом, мессенджером и кнопкой быстрой записи. Полная поддержка безопасных зон современных смартфонов (`env(safe-area-inset-bottom)`).
* **Touch-оптимизация**: увеличенные области нажатия (min 44×44px) для комфортного взаимодействия на любом сенсорном экране.

### ⚡ Динамика и микро-взаимодействия
* **Интерактивный каталог услуг**: фильтрация категорий («Все», «Акции месяца», «Импланты», «Терапия», «Брекеты», «Детям») без перезагрузки страницы.
* **Умная форма заявки**:
  * Клик по кнопке «Записаться» в карточке услуги автоматически предвыбирает нужную позицию в форме и плавно прокручивает страницу к ней.
  * Интерактивные чипсы выбора времени («В ближайшее время», «Сегодня вечером», «Ночью (24/7)», «Завтра»).
  * Анимированное подтверждение успешной отправки заявки.
* **Интерактивный FAQ-аккордеон**: плавное раскрытие ответов на ключевые страхи и вопросы пациентов с анимированным поворотом индикатора.
* **Карусель отзывов**: горизонтальный скролл с навигационными стрелками и поддержкой свайпов на тачскринах.
* **Анимации и эффекты**:
  * Пульсирующий индикатор живого дежурства (**Radar Pulse**) для круглосуточного режима 24/7.
  * Деликатный световой блик (**Button Shimmer**) на конверсионных CTA-кнопках.
  * Поочередное плавное появление секций и карточек (**Staggered Scroll Fade-in**) через `IntersectionObserver`.
  * Динамическое сжатие шапки при прокрутке страницы (**Sticky Header Blur**).

### 🎨 Дизайн и типографика
* **Шрифт Onest**: чистая медицинская типографика без кричащих супер-жирных начертаний (заголовки `font-weight: 400`).
* **Цветовая палитра**:
  * Основной медицинский акцент: `Teal #0D7F75`
  * Глубокий оттенок: `Teal Dark #0A6159`
  * Светлый премиальный фон: `#EAEDEC`
  * Текстовый контраст: `#1A2A28`
* **Zero-Emoji Policy**: строго векторные SVG-иконки (Lucide / Phosphor Icons) с единым стилем линий и адаптивными цветами.

## 🚀 Локальный запуск

Лендинг является статическим веб-приложением и запускается любым локальным сервером:

### Вариант 1. С помощью Python:
```bash
python -m http.server 3000
```
Затем откройте [http://localhost:3000](http://localhost:3000).

### Вариант 2. С помощью Node.js (npx serve):
```bash
npx serve .
```

### Вариант 3. Расширение Live Server в VS Code / IDE:
Нажмите правой кнопкой мыши на `index.html` → **Open with Live Server**.
